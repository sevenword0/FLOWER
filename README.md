# FLOWER — WebGPU 절차적 꽃 개화 시뮬레이터

한국어 | [English](README.en.md)

WebGPU로 꽃이 봉오리에서 만개까지 피어나는 과정을 실시간으로 그리는 **단일 HTML 앱**입니다.
꽃잎·꽃술·꽃받침·잎을 모두 수식으로 만들어 내며(절차적 생성), 외부 라이브러리나 설치가 전혀 필요 없습니다.

## 바로 보기

**https://sevenword0.github.io/FLOWER/**

주소를 열면 곧바로 실행됩니다. 설치·로그인·다운로드가 없습니다.

### 지원 브라우저

| 브라우저 | WebGPU 기본 지원 버전 |
| --- | --- |
| Chrome / Edge (Windows · macOS · ChromeOS) | 113 이상 |
| Chrome (Android) | 121 이상 |
| Safari (macOS · iOS · iPadOS) | 26 이상 |
| Firefox (Windows) | 141 이상 |

지원하지 않는 브라우저에서는 꽃 대신 "WebGPU를 사용할 수 없습니다" 안내 화면이 나옵니다.
이 경우 위 표의 브라우저 최신 버전으로 열어 주세요.

## 사용 방법

1. 위 주소를 엽니다. 장미가 자동으로 피어나기 시작합니다.
2. 화면을 **드래그**하면 꽃을 돌려 볼 수 있고, **마우스 휠**(모바일은 두 손가락 벌리기)로 확대·축소합니다.
3. 왼쪽 패널의 네 개 탭으로 꽃과 화면을 바꿉니다.

| 탭 | 할 수 있는 일 |
| --- | --- |
| **생성** | 꽃 종류(프리셋 8종) 선택, 무작위 생성, 다시 피우기, 자동 순환, 현재 설정 복사. 개화 정도·속도·중심↔외곽 편차·가속(이징) 조절 |
| **형태** | 꽃잎 수·겹 수·길이·너비·최대폭 위치·끝 둥글기, 말림(컵), 뿌리·중간·끝 곡률, 벌어짐, 주름, 꽃받침, 색상 |
| **조명** | 광택(스페큘러), 주광 방향·고도, AO·SSGI·소프트 섀도우 켜기/끄기와 세기, 꽃잎 정밀도 |
| **장면** | 줄기·잎 표시, 자동 회전, 배경 5종 |

> 개화 과정을 직접 넘겨 보려면 **생성** 탭에서 "자동 개화"를 끄고 "개화 정도" 슬라이더를 움직이세요.

## 프리셋 8종

각 프리셋은 실제 꽃의 구조와 피는 방식을 반영합니다.

| 프리셋 | 구조 | 개화 방식 |
| --- | --- | --- |
| 장미 | 나선형으로 겹친 꽃잎 약 30장, 꽃받침 5장 | 바깥 꽃잎부터 젖혀지고 중심은 오므린 채 유지 |
| 데이지 | 한 겹의 가는 설상화 21장 + 중앙 관상화 원반 | 평평하게 펼쳐짐 |
| 해바라기 | 뾰족한 설상화 + 황금각 나선 배열의 큰 원반 | 가장자리에서 안쪽으로 |
| 튤립 | 3+3 꽃덮이 6장, 수술 6개 | 컵 모양을 유지한 채 조금만 열림 |
| 백합 | 3+3 꽃덮이 6장, 긴 수술·암술 | 끝이 강하게 뒤로 젖혀짐 |
| 연꽃 | 넓은 꽃잎 여러 겹 + 중앙 연밥, 수술 고리 | 겹겹이 바깥부터 |
| 벚꽃 | 끝이 갈라진 꽃잎 5장, 가는 수술 다수 | 한꺼번에 활짝 |
| 달리아 | 촘촘한 나선형 꽃잎, 대롱처럼 말린 형태 | 바깥에서 안쪽으로 |

## 렌더링 구성

- **2패스 디퍼드 렌더링**: 1패스에서 색·법선·위치를 G-buffer(다중 렌더 타깃, 4× MSAA)에 기록하고 2패스에서 합성합니다.
- **PBR 조명**: GGX 마이크로패싯 스페큘러 + 프레넬, 하늘/지면 반구 환경광, 얇은 꽃잎의 역광 투과.
- **AO**(앰비언트 오클루전), **SSGI**(화면공간 1바운스 전역조명), **소프트 섀도우**(광원 방향 화면공간 레이마칭).
- **ACES 톤매핑**.
- 꽃잎·꽃술·관상화는 인스턴싱으로 한 번에 그리고, 개화·말림·젖힘은 정점 셰이더에서 계산합니다.

## 내 컴퓨터에서 실행

`index.html` 파일 하나만 내려받아 WebGPU 지원 브라우저로 열면 됩니다. 인터넷 연결이나 추가 설치가 필요 없습니다.

## 배포 (GitHub Pages)

`main` 브랜치에 변경이 들어오면 `.github/workflows/pages.yml` 워크플로가 리포 루트를 GitHub Pages에 자동으로 다시 배포합니다.
보통 1~2분 뒤 위 주소에 반영되며, 브라우저 캐시 때문에 최대 10분쯤 이전 화면이 보일 수 있습니다.

- 수동 실행: 리포 **Actions** 탭 → *Deploy to GitHub Pages* → *Run workflow*
- 배포가 실패하면: 리포 **Settings → Pages → Build and deployment → Source** 가 **GitHub Actions** 로 되어 있는지 확인하세요.
- 워크플로는 리포 **루트 전체**를 공개하므로, 리포에 추가한 다른 파일도 같은 주소 아래에서 열람할 수 있게 됩니다.
