# FLOWER — WebGPU 절차적 꽃 개화 시뮬레이터

한국어 | [English](README.en.md)

WebGPU로 꽃이 봉오리에서 만개까지 피어나는 과정을 실시간으로 그리는 **단일 HTML 앱**입니다.
꽃잎·꽃술·꽃받침·잎을 모두 수식으로 만들어 내며(절차적 생성), 외부 라이브러리나 설치가 전혀 필요 없습니다.

## 바로 보기

**https://sevenword0.github.io/FLOWER/**

주소를 열면 곧바로 실행됩니다. 설치·로그인·다운로드가 없습니다.

### 지원 브라우저

| 브라우저 | WebGPU 기본 지원 버전 |
| --- | --- |
| Chrome / Edge (Windows · macOS · ChromeOS) | 113 이상 |
| Chrome (Android) | 121 이상 |
| Safari (macOS · iOS · iPadOS) | 26 이상 |
| Firefox (Windows) | 141 이상 |

지원하지 않는 브라우저에서는 꽃 대신 "WebGPU를 사용할 수 없습니다" 안내 화면이 나옵니다.
이 경우 위 표의 브라우저 최신 버전으로 열어 주세요.

## 사용 방법

1. 위 주소를 엽니다. 장미가 자동으로 피어나기 시작합니다.
2. 화면을 **드래그**하면 꽃을 돌려 볼 수 있고, **마우스 휠**(모바일은 두 손가락 벌리기)로 확대·축소합니다.
3. 왼쪽 패널의 네 개 탭으로 꽃과 화면을 바꿉니다.

| 탭 | 할 수 있는 일 |
| --- | --- |
| **생성** | 꽃 종류(프리셋 8종) 선택, 무작위 생성, 다시 피우기, 자동 순환, 현재 설정 복사. 개화 정도·속도·중심↔외곽 편차·가속(이징) 조절 |
| **형태** | 꽃잎 수·겹 수·길이·너비·최대폭 위치·끝 둥글기, 말림(컵), 뿌리·중간·끝 곡률, 벌어짐, 주름, 꽃받침, 색상 |
| **조명** | 광택(스페큘러), 주광 방향·고도, AO·SSGI·소프트 섀도우 켜기/끄기와 세기, 폴리곤 예산(삼각형 수 상한 4단계) |
| **장면** | 줄기·잎 표시, 자동 회전, 배경 5종 |

> 개화 과정을 직접 넘겨 보려면 **생성** 탭에서 "개화 정도" 슬라이더를 움직이세요(움직이면 자동 개화는 저절로 꺼집니다).
>
> 화면 아래쪽에는 초당 프레임 수, 부품 개수, 현재 삼각형 수가 표시됩니다.

## 프리셋 8종

각 프리셋은 실제 꽃의 구조와 피는 방식을 반영합니다.

| 프리셋 | 구조 | 개화 방식 |
| --- | --- | --- |
| 장미 | 나선형으로 여러 겹 겹친 꽃잎, 꽃받침 5장 | 바깥 꽃잎부터 젖혀지고 중심은 오므린 채 유지 |
| 데이지 | 한 겹의 가는 설상화 26장 + 중앙 관상화 원반 | 꽃잎마다 조금씩 시차를 두고 평평하게 펼쳐짐 |
| 해바라기 | 한 겹의 설상화 30장 + 황금각 나선 배열의 큰 원반, 총포 | 원반 위로 접혀 있던 설상화가 일어서며 펼쳐짐 |
| 튤립 | 3+3 꽃덮이 6장, 수술 6개 | 겹쳐 감싼 봉오리에서 잔 모양으로 열림 |
| 백합 | 3+3 꽃덮이 6장, 긴 수술·암술 | 넓게 벌어지며 끝이 뒤로 젖혀짐 |
| 연꽃 | 넓은 꽃잎 여러 겹 + 중앙 연밥, 수술 고리 | 겹겹이 바깥부터 |
| 벚꽃 | 끝이 갈라진 꽃잎 5장, 가는 수술 다수. 한 가지에 4송이 | 한꺼번에 활짝 |
| 달리아 | 촘촘한 나선형 꽃잎, 대롱처럼 말린 형태 | 바깥 줄부터 한 줄씩 안쪽으로 |

## 꽃잎 상호작용

꽃잎은 서로를 알고 움직입니다. 꽃잎마다 밑동에서 끝까지의 곡선(등뼈)을 점 8개로 줄여, 꽃 전체를 한꺼번에 계산합니다.

- **붙잡기와 풀림**: 닫힌 꽃받침과 바깥 꽃잎이 안쪽 꽃잎을 붙잡고 있다가, 바깥 겹부터 차례로 풀립니다. 수술도 안쪽 꽃잎이 열려야 펼쳐집니다.
- **포개짐**: 안쪽·바깥쪽 꽃잎은 간격을 두고 포개지며 서로 뚫고 지나가지 않도록 밀어냅니다.
- **엇갈림**: 같은 겹의 이웃 꽃잎은 한쪽 가장자리는 위로, 다른 쪽은 아래로 엇갈려 얹힙니다.
- **탄성**: 풀려난 꽃잎은 살짝 튕겼다가 자리를 잡습니다. 그래도 "개화 정도" 슬라이더의 같은 위치에서는 항상 같은 모양이 됩니다.

한계: 꽃잎은 밑동을 축으로 통째로 밀리는 축소 모델입니다. 접촉 부위만 국소적으로 눌리는 변형은 표현하지 않습니다. 꽃잎이 매우 많은 꽃의 봉오리 상태와 무작위 생성 꽃에서는 겹침이 일부 남을 수 있습니다. "Z 반전"이나 꽃잎 회전(X·Y·Z)을 쓰면 상호작용 계산을 끄고 각 꽃잎을 독립적으로 움직입니다.

## 폴리곤 예산

꽃 전체의 삼각형 수에 상한을 두고, 그 안에서 부품별 정밀도를 자동으로 나눕니다.

| 단계 | 삼각형 상한 |
| --- | --- |
| 낮음 | 약 4만 |
| 보통 (기본값) | 약 10만 |
| 높음 | 약 20만 |
| 최고 | 약 40만 |

- 꽃잎이 적은 꽃(장미·튤립·백합)은 꽃잎 한 장을 촘촘하게, 꽃잎이 많은 꽃(달리아)은 한 장을 성기게 그립니다.
- 잎맥·반점·홈 같은 세부는 삼각형이 아니라 표면 음영으로 표현합니다.
- 화면이 느리면(평균 프레임 시간이 33ms를 넘으면) 내부 해상도를 먼저 낮추고, 그래도 느리면 폴리곤 예산을 한 단계씩 낮춥니다. 한번 낮춘 품질은 자동으로 다시 올리지 않습니다.

## 렌더링 구성

- **디퍼드 렌더링**: 그림자 맵 → G-buffer(직접광·법선·위치·환경광, 다중 렌더 타깃, 4× MSAA) → 절반 해상도 AO/SSGI → 블러 → 글로우 → 합성 순서로 그립니다.
- **PBR 조명**: GGX 마이크로패싯 스페큘러 + 프레넬, 부품별 재질(광택·벨벳 광·얇은 꽃잎의 역광 투과), 주광·반구 환경광·테두리광.
- **소프트 섀도우**: 광원 시점의 그림자 맵(2048², 거리에 따라 번지는 반그림자).
- **AO**(앰비언트 오클루전)와 **SSGI**(화면공간 1바운스 전역조명)는 환경광에 적용됩니다.
- **ACES 톤매핑**, 글로우, 디더링.
- **절차적 표면**: 꽃잎의 색 번짐·잎맥·종별 무늬(백합 반점, 튤립 밑동 무늬 등)와 잎의 잎맥을 수식으로 그립니다.
- 꽃잎·꽃술·관상화는 인스턴싱으로 그립니다. 꽃잎의 자세는 CPU에서 풀고, 그 결과로 정점 셰이더가 면을 변형합니다.
- 내부 렌더 해상도는 약 230만 화소로 제한됩니다(고해상도 휴대폰의 메모리 보호).

## 확인하지 못한 환경

자동 검사는 그래픽카드가 없는 서버의 소프트웨어 렌더러(Chromium)에서만 수행했습니다. 실제 그래픽카드, Safari, Firefox, 실제 휴대폰에서의 모양과 속도는 확인하지 못했습니다.

## 내 컴퓨터에서 실행

`index.html` 파일 하나만 내려받아 WebGPU 지원 브라우저로 열면 됩니다. 인터넷 연결이나 추가 설치가 필요 없습니다.

## 배포 (GitHub Pages)

`main` 브랜치에 변경이 들어오면 `.github/workflows/pages.yml` 워크플로가 리포 루트를 GitHub Pages에 자동으로 다시 배포합니다.
보통 1~2분 뒤 위 주소에 반영되며, 브라우저 캐시 때문에 최대 10분쯤 이전 화면이 보일 수 있습니다.

- 수동 실행: 리포 **Actions** 탭 → *Deploy to GitHub Pages* → *Run workflow*
- 배포가 실패하면: 리포 **Settings → Pages → Build and deployment → Source** 가 **GitHub Actions** 로 되어 있는지 확인하세요.
- 워크플로는 리포 **루트 전체**를 공개하므로, 리포에 추가한 다른 파일도 같은 주소 아래에서 열람할 수 있게 됩니다.
